# OrganFour

Four-bar live organ desk. The unfinished loop already has hats and a pad. It still does not feel like a room. OrganFour seats FluidR3 piano, nylon, upright, kit, trumpet, and violin so the chorus finally has a church-and-bar chair.

Distinct from BorrowFour (harmony leave), StrumFour (nylon rhythm), BreathFour (space), HarmFour (harmonica), and PedalFour (bass pedal).

## Use

Open the site. Tap **Dry pocket** to hear the stuck loop. Tap **Organ + return** to hear the four organ bars plus the landing. Copy the punch list into your DAW or download MIDI.

Live samples come from the shared FluidR3 chair bank used across the finish-desk line.
